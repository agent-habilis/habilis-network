# habilis-network-iroh-transport-util

Path selection and GSO unbatching shared by the two habilis-network iroh custom
transports (`habilis-network-iroh-webrtc-transport` and
`habilis-network-iroh-multihop-transport`).

A small crate with no network code of its own. See `src/lib.rs` for the
API and for why it is a crate rather than a module.
